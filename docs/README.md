## Pré-requisitos

- **Node.js** 20+
- **Rust** 1.75+
- [Pré-requisitos do Tauri](https://tauri.app/v1/guides/getting-started/prerequisites) para sua plataforma

## Executando a IDE

```bash
npm install
npm run tauri:dev
```

Para gerar o executável:

```bash
npm run tauri:build
```
